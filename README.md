# Análisis de carga docente y similitud de contenidos programáticos

Proyecto enfocado en el análisis de la carga docente y el desarrollo de un modelo de similitud de contenidos académicos mediante técnicas de procesamiento de lenguaje natural (NLP).

## Objetivo

Analizar la asignación de horas de docentes e identificar oportunidades de optimización, así como evaluar la similitud entre asignaturas para apoyar procesos académicos.

## Componentes

### Análisis de carga docente
- Procesamiento y limpieza de datos
- Identificación de horas libres y sobrecarga
- Análisis por tipo de contrato

### Similitud de contenidos
- Vectorización de textos con TF-IDF
- Cálculo de similitud con cosine similarity
- Clasificación por niveles de similitud.

## Tecnologías
- Python
- Pandas
- Scikit-learn
- Power BI

## Estructura
- `notebooks/`: notebooks principales del proyecto
